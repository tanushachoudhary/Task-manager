# Task Manager

A modern and customizable task manager web application built with React, TypeScript, Vite, shadcn-ui, and Tailwind CSS.

## Features

- 🗂 Organize your tasks efficiently with intuitive UI components.
- 🎨 Modern design using shadcn-ui and Tailwind CSS.
- ⚡ Fast and optimized development workflow powered by Vite.
- 🌙 Supports dark mode for comfortable viewing.
- 🔁 Drag-and-drop and interactive UI for managing tasks.
- 🧩 Modular and reusable React components.

## Getting Started

If you want to work locally using your own IDE, you can clone this repo and push changes.  
The only requirement is having Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Steps:

```sh
# Step 1: Clone the repository
git clone https://github.com/tanushachoudhary/Task-manager.git

# Step 2: Navigate to the project directory
cd Task-manager

# Step 3: Install the necessary dependencies
npm install

# Step 4: Start the development server with auto-reloading and an instant preview
npm run dev
```

## Tech Stack

- [React](https://react.dev/) & [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [shadcn-ui](https://ui.shadcn.com/)
- [Radix UI](https://www.radix-ui.com/) (for accessible UI primitives)

## Folder Structure

- `src/` - Main source code
  - `components/ui/` - Custom and reusable UI components (e.g., Button, Sidebar, Carousel, Pagination, etc.)
  - `index.css` - Global and theme styles

## Customization

- The project uses a theme system via CSS variables for easy color and style changes.
- All UI components are built to be reusable and easily extendable.
- Supports both light and dark themes out-of-the-box.
